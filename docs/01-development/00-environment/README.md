# 环境搭建 (DEV-00)

本章将帮助你搭建Go开发环境，运行第一个Go程序。

## 学习目标

完成本章后，你将能够：

- 在 macOS/Windows/Linux 上安装Go
- 理解GOPATH与Go Modules的区别
- 配置VS Code进行Go开发
- 编写并运行第一个Go程序

## 章节内容

| 文档 | 说明 | 预计时间 |
|------|------|----------|
| [安装指南](./install-guide.md) | Go在各平台的安装步骤 | 30min |
| [GOPATH与Modules](./gopath-modules.md) | 理解Go的依赖管理演进 | 20min |
| [VS Code配置](./vscode-setup.md) | 配置Go开发环境 | 20min |
| [第一个程序](./first-program.md) | Hello World与基本结构 | 30min |

## 前置要求

- 一台 macOS/Windows/Linux 电脑
- 基本的命令行操作能力
- VS Code 或类似编辑器

## 难度

🟢 **入门** - 适合零基础学习者

## 验收标准

完成本章后，请确认你能够：

- [ ] 运行 `go version` 显示正确的Go版本
- [ ] 运行 `go env` 查看Go环境配置
- [ ] 创建并运行 Hello World 程序
- [ ] 在VS Code中获得代码补全和语法高亮
