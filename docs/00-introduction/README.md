# 教程介绍与学习路径

欢迎来到《前端工程师Go后端开发学习教程》！

## 教程目标

本教程专为前端工程师设计，帮助你快速掌握Go语言后端开发技能。我们将：

1. **建立概念映射** - 将Go概念与你熟悉的JavaScript/TypeScript进行对比
2. **实践驱动学习** - 每个知识点都有可运行的代码示例
3. **渐进式深入** - 从基础语法到生产级服务部署

## 你将学到什么

完成本教程后，你将能够：

- ✅ 编写符合Go语言惯例的代码
- ✅ 理解并利用Go的并发特性构建高性能服务
- ✅ 使用主流框架（Gin）开发RESTful API
- ✅ 操作PostgreSQL数据库（原生SQL和GORM）
- ✅ 实现完整的认证授权系统（JWT、OAuth2）
- ✅ 集成Redis缓存和RabbitMQ消息队列
- ✅ 构建可观测的生产级服务（日志、监控、追踪）
- ✅ 使用Docker部署Go应用

## 前置知识

在开始学习之前，请确保你具备以下基础：

- 熟悉JavaScript或TypeScript
- 了解基本的HTTP协议和RESTful API概念
- 有基本的命令行操作能力
- 会使用VS Code或类似IDE
- 了解基本的SQL操作（SELECT/INSERT/UPDATE/DELETE）
- 了解Docker基本使用（可选，但推荐）

## 难度标识

本教程使用以下标识来标记内容难度：

- 🟢 **入门** - 基础概念，适合初学者
- 🟡 **中级** - 需要一定基础，实际项目常用
- 🔴 **高级** - 复杂场景，生产环境必备

## 如何使用本教程

### 方式一：顺序学习（推荐）

按照章节顺序从头到尾学习，这是最完整的学习路径。

### 方式二：按需学习

如果你已有一定Go基础，可以直接跳到感兴趣的章节：

- **急需开发API？** → 从 [06-Web API](../06-web-api/) 开始
- **需要操作数据库？** → 从 [08-PostgreSQL](../08-database-sql/) 或 [09-GORM](../09-gorm/) 开始
- **关注性能优化？** → 从 [04-并发编程](../04-concurrency/) 和 [10-缓存](../10-caching/) 开始

准备好了吗？让我们从 [环境搭建](../01-environment-setup/) 开始！
