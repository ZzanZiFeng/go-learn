# Go后端学习教程 - 总体介绍

欢迎来到《Go后端学习教程》！本教程专为前端工程师设计，采用**四轨并行结构**，帮助你系统掌握Go语言后端开发技能。

## 四轨结构概述

本教程将学习内容组织为四条独立但相互关联的轨道：

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        Go后端学习教程                                    │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  ┌───────────────┐  ┌───────────────┐  ┌───────────────┐  ┌───────────────┐
│  │  开发教程      │  │  实战教程      │  │  部署教程      │  │  测试教程      │
│  │  (Development) │  │  (Practice)   │  │  (Deployment) │  │  (Testing)    │
│  ├───────────────┤  ├───────────────┤  ├───────────────┤  ├───────────────┤
│  │ 12个章节      │  │ 4个项目       │  │ 5个章节       │  │ 5个章节       │
│  │ ~52小时       │  │ ~30小时       │  │ ~13小时       │  │ ~13小时       │
│  └───────────────┘  └───────────────┘  └───────────────┘  └───────────────┘
│                                                                         │
```

## 前置知识

在开始学习之前，请确保你具备以下基础：

- ✅ 熟悉JavaScript或TypeScript
- ✅ 了解基本的HTTP协议和RESTful API概念
- ✅ 有基本的命令行操作能力
- ✅ 会使用VS Code或类似IDE
- ✅ 了解基本的SQL操作（SELECT/INSERT/UPDATE/DELETE）
- ✅ 了解Docker基本使用（可选，但推荐）

## 学习目标

完成本教程后，你将能够：

- 编写符合Go语言惯例的代码
- 理解并利用Go的并发特性构建高性能服务
- 使用Gin框架开发RESTful API
- 操作PostgreSQL数据库（原生SQL和GORM）
- 实现完整的认证授权系统（JWT、OAuth2、RBAC）
- 集成Redis缓存和RabbitMQ消息队列
- 构建可观测的生产级服务（日志、监控、追踪）
- 使用Docker部署Go应用
- 编写高质量的测试代码

## 学习路径推荐

### 路径A：系统学习（推荐新手）

适合刚接触后端开发的前端工程师：

```
开发教程(全部) → 实战教程(01-02) → 测试教程(01-02) → 部署教程(01-02) → 实战教程(03-04)
```

### 路径B：快速上手（有后端基础）

适合有其他后端语言经验的开发者：

```
开发教程(00-01) → 实战教程(01) → 开发教程(05-08) → 实战教程(02) → 部署教程 → 测试教程
```

### 路径C：项目驱动（边做边学）

适合喜欢动手实践的学习者：

```
实战教程(01) ←→ 开发教程(按需) → 实战教程(02) ←→ 开发教程(按需) → 部署+测试
```
